# MRT Currency Check 📱

A simple Android application for checking MRT currency/fare information.

## 📱 About the Project

**MRT Currency Check** is an Android application designed to make checking MRT currency/fare information simple and convenient.

## ✨ Features

- 🚇 MRT currency/fare checking
- 📱 Simple Android interface
- ⚡ Lightweight application
- 🎨 Easy-to-use UI

## 🛠️ Technologies Used

- **Kotlin**
- **Android**
- **Jetpack Compose**
- **Gradle**

## 💻 Run the Project Locally

### Requirements

- Android Studio
- Android SDK
- JDK

### Steps

1. Clone the repository:

```bash
git clone https://github.com/badhon-droid/MRT-Currency-Check.git
```

2. Open the project in Android Studio.

3. Allow Gradle to synchronize and download the required dependencies.

4. Connect an Android device or start an Android emulator.

5. Run the application.
